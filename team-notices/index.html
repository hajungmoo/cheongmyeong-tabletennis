휴대폰 알림 설정

알림 상태를 확인하고 있어요

아래에서 내 휴대폰을 선택해주세요.

  1. 1
    Chrome에서 알림장 열기

    코치님에게 받은 초대코드로 연결해요.

  2. 2
    큰 ‘알림 켜기’ 버튼 누르기

    알림 허용 창이 뜨면 ‘허용’을 눌러요.

  3. 3
    ‘알림 켜짐’ 표시 확인하기

    이제 이 휴대폰으로 새 공지를 받아요.

실수로 ‘차단’을 눌렀나요?

Chrome에서 이 알림장을 열고, 주소창 왼쪽 페이지 정보 → 권한 → 알림 → 허용을 선택해주세요.

휴대폰 설정의 알림에서도 Chrome 또는 청명 알림장이 허용되어 있는지 확인해주세요.

  1. 1
    Safari에서 홈 화면에 추가

    공유 → 홈 화면에 추가 → 추가를 눌러요.

  2. 2
    홈 화면의 청명 알림장 열기

    코치님에게 받은 초대코드로 연결해요.

  3. 3
    ‘알림 켜기’ → ‘허용’ 누르기

    ‘알림 켜짐’이 표시되면 준비 완료!

아이폰은 홈 화면에 추가한 앱에서 알림을 켤 수 있어요. iOS 16.4 이상이 필요해요.

실수로 ‘허용 안 함’을 눌렀나요?

아이폰 설정 → 알림 → 청명 알림장 → 알림 허용을 켜고, 홈 화면의 알림장으로 돌아와주세요.

알림 소리는 휴대폰의 무음·방해금지 설정에 따라 달라요.

홈 화면에 청명 알림장

처음 한 번만 설치하고, 알림을 허용해주세요.

아이폰 · Safari

  1. 이 페이지를 Safari로 열어요.
  2. 공유 버튼 → 홈 화면에 추가 → 추가를 눌러요.
  3. 홈 화면의 청명 알림장을 열고 초대코드로 연결해요.
  4. 알림 켜기 → 허용을 눌러요.

iOS 16.4 이상에서 알림을 받을 수 있어요.

갤럭시 · Chrome

  1. Chrome 메뉴 ⋮ → 홈 화면에 추가 / 앱 설치를 눌러요.
  2. 앱을 열고 초대코드로 연결한 뒤 알림 켜기를 눌러요.

알림은 휴대폰의 무음·방해금지 설정을 따릅니다. 인터넷에 연결되어 있어야 받을 수 있어요.
