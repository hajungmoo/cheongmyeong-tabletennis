MANUAL PLAYER DB
새 학교명을 입력하면 학교 DB도 자동으로 생성됩니다. 1~3학년은 자동으로 ‘랭킹 없음’, 4~6학년은 ‘랭킹 미등록’으로 저장되며 나중에 랭킹 Excel 업데이트 시 자동 연결할 수 있습니다.
현재 랭킹표와 같은 형식의 Excel 파일(통합 / 4학년 / 5학년 / 6학년 시트)을 넣으면 기존 선수의 랭킹·학년·소속을 갱신하고, 새 선수는 자동 추가합니다. 기존 경기·리그 기록은 유지됩니다.
1~3학년은 랭킹 없음. 4~6학년은 업로드한 최신 남·녀 랭킹 파일 기준으로 표시합니다. 선수 카드의 '수정'에서 전학/학교변경도 가능합니다.
