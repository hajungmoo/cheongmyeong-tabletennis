# 청명 알림장 종료 (2026-10-03)

알림장 웹 화면은 종료 안내로 대체합니다. 홈페이지, 홈페이지 관리자, 경기기록 프로그램, 학부모 경기조회 및 해당 데이터는 변경하지 않습니다.

## 서버 종료

Firebase 프로젝트 관리 계정으로 로그인한 Google Cloud Shell에서 저장소를 받은 후 `bash notice-backend/retire.sh`를 실행합니다.

스크립트는 `cheongmyeong-tabletennis` 프로젝트 서울 리전의 `cm-notices` 코드베이스 함수 3개(`cmTeamNotices`, `cmTeamNoticeQueued`, `cmTeamNoticeDispatch`)를 확인합니다. 예약 작업을 일시중지한 뒤 API는 HTTP 410 종료 응답, 자동 발송 함수들은 아무 작업도 하지 않는 코드로 배포합니다. 예약 작업이 PAUSED인지, API가 종료 응답인지 확인해야 완료입니다. 다른 함수가 같은 코드베이스에 있거나 권한 확인에 실패하면 중단합니다.

공지 DB와 기록은 보존합니다. DB·Storage·보안 규칙·Authentication·결제 플랜을 변경하지 않습니다. 종료 서버는 Firebase Admin SDK를 초기화하지 않으며 DB 접근이나 푸시 발송을 하지 않습니다. Git에 코드를 반영한 것만으로 Firebase 서버가 종료되지는 않습니다.

## 이미 설치한 알림장

`/team-notices/sw.js`는 설치된 앱의 종료 처리를 위해 남깁니다. 기기가 온라인에서 업데이트를 받거나 종료 화면에 방문하면 알림장 전용 푸시 구독, 서비스워커, `cm-notices-shell-` 캐시와 `cm-notices-member` 값만 정리합니다. 사이트 전체 저장소를 지우거나 홈페이지·경기관리 로그아웃을 실행하지 않습니다. 홈 화면 아이콘은 사용자가 삭제해야 합니다.

## 복원

기존 코드는 Git의 종료 직전 버전에 보존됩니다. 운영자의 별도 요청과 예약 공지 검토 후 이전 버전을 복원·배포할 수 있습니다. 기존 `deploy.sh`도 종료 스크립트를 호출하므로 실수로 서비스를 재개하지 않습니다.
